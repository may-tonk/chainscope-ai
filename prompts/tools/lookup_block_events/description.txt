工具：lookup_block_events

用途：按链和区块哈希，查询当前已索引数据中的相关事件，返回有限引用及数据范围。

适用：用户明确指定区块，或其他分析需要对区块中的已采集事件做定位。
不适用：用交易哈希冒充区块哈希，宣称已经获取全区块全部交易，或重采尚未索引的数据。

参数语义：chain_id 和 block_hash 用于定位；token_address 为可选代币筛选。page_size 控制单页数量，cursor 只续取相同查询的服务端游标。区块哈希与交易哈希外形一致，语义不明确时由主 Agent 追问，不盲选工具。
字段类型和必填性由 Pydantic 输入模型定义。

结果使用：分页未取完不能把当前页当作区块总量。实际采集了某代币事件不代表覆盖区块全部活动。空结果只说明当前索引中未找到；错误不能转为空结果。
状态处理：保留 partial 限制及 unsupported、needs_input、failed、cancelled 的真实含义。

执行内容：分页返回正式 Transfer 与已补齐 Swap 的明细及引用。未指定代币且授权数据集不唯一时须明确代币。只用既有区块缓存或已采集 Transfer 定位区块，不访问链节点；两者均缺失时未找到不表示区块不存在。实际截止和独立 Swap 补采限制随结果交付。分页游标绑定用户、修订、条件和快照。

示例意图：“看看这个区块里有哪些 BEM 相关事件。”——使用区块对象查询已索引事件，后续按问题需要决定是否继续分析。
